Стандартный `boot.wim` из ISO Windows часто не содержит драйверов для новых сетевых карт, USB-C адаптеров или контроллеров NVMe/RAID (Intel VMD, VirtIO). OMB позволяет загружать пакеты драйверов один раз и подключать их к любым загрузкам Windows и Strelec.

## Каталог драйверов (`/drivers`)

В разделе [Библиотека → Драйверы](/drivers) доступны два способа загрузки:

- **Папка с драйверами** — выберите локальный каталог на компьютере, браузер передаст всю структуру с файлами `.inf`, `.sys`, `.cat`.
- **ZIP-архив** — загрузите готовый архив драйверов от производителя (Dell WinPE Driver Pack, Lenovo, VirtIO и др.).

OMB разбирает содержимое архива, индексирует все `.inf`-файлы, вычисляет SHA-256 пакета и сохраняет инвентарь в базе. Состав любого пакета открывается по клику в модальном окне.

> [!NOTE]
> Для сетевой установки в WinPE обычно достаточно драйверов двух классов: **Net** (сетевая карта, чтобы подключиться к шаре `[ombisos]`) и **SCSIAdapter / HDC** (контроллер дисков, чтобы Windows Setup увидел накопитель).

## Подключение драйверов и дедупликация `boot.wim`

Выбор драйверов происходит прямо на форме [Новая загрузка](/installations/new):

- если в пакете один `.inf`, выводится одна карточка с галочкой;
- если в пакете несколько `.inf`, можно отметить весь пакет целиком или выбрать отдельные нужные `.inf`.

При сборке `omb-agent` внедряет выбранные драйверы в копию активного `boot.wim` утилитой `wimlib-imagex` — это одинаково работает для `boot.wim` из базового ISO, при подмене на `boot.wim` из другого Windows ISO и для отдельного `boot.wim` со вкладки **boot.wim** в [Библиотека → Образы](/images). Готовые образы `boot.wim` хранятся в `/srv/omb/tftp/windows-driver-wims/` с **дедупликацией по SHA-256** (исходный `boot.wim` + набор `.inf`): если несколько загрузок используют один и тот же `boot.wim` и набор драйверов, образ не дублируется на диске и не пересобирается повторно.

Занимаемое конфигурациями место отображается в таблице конфигураций WinPE и в разделе [Система → Хранилища](/storages) без двойного учёта общих `boot.wim`.

## Сервисный образ Strelec (`SSTR`)

OMB распознаёт сервисные ISO-образы Strelec x64 (`SSTR`) автоматически при проверке ISO:

1. При создании загрузки из образа Strelec вы выбираете редакцию **WinPE 11** или **WinPE 10**, а при необходимости подключаете пакеты драйверов WinPE. Поля файлов ответов XML и Autoinstall для Strelec скрываются.
2. `omb-agent` адаптирует `BCD` и собирает скрипт подключения с учётом настроек ожидания сети из [Система → Сеть](/network).
3. При загрузке на клиенте драйверы подгружаются по одному — ошибка отдельного несовместимого `.inf` не останавливает загрузку и записывается в `X:\omb-driver.log`.
4. Этапы подключения сетевой шары и монтирования сервисного образа фиксируются в `X:\omb-strelec.log`.

> [!IMPORTANT]
> Как и для Windows, URL конфигурации `windows-driver-configs/*/omb-setup.cmd` для Strelec отдаётся только в загрузочной PXE-сети (`200`), а из сети управления возвращает `404`.
