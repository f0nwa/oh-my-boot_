OMB поддерживает одновременную работу с несколькими образами Ubuntu Desktop amd64 — как в интерактивном режиме Live/Install, так и с полной автоматизацией через NoCloud Autoinstall.

## Подготовка образа Ubuntu ISO

1. Загрузите ISO Ubuntu Desktop в любое хранилище и запустите «Проверить ISO» на странице [Библиотека → Образы ISO](/images).
2. При создании загрузки `omb-agent` извлекает из образа в `/srv/omb/tftp/ubuntu-sources/<id>/`:
   - ядро `vmlinuz` и образ начальной загрузки `initrd`;
   - подписанный загрузчик Ubuntu `shim` (`ubuntu/bootx64.efi`) — нужен для прохождения Secure Boot при переходе от iPXE к ядру Linux;
   - каталог доступных наборов приложений для конструктора.

Для быстрого открытия страниц `/installations` и `/installations/new` статус готовности источников Ubuntu кэшируется в памяти на 30 с (с защитой `singleflight`), но перед публикацией меню и созданием новой загрузки всегда выполняется строгая проверка доступности файлов.

> [!IMPORTANT]
> Загрузчик `casper` скачивает ISO Ubuntu по HTTP целиком в оперативную память клиентской машины. Для современных образов Ubuntu Desktop (~6,5 ГБ) клиенту требуется **более 4 ГБ ОЗУ** (на стенде проверено на машинах с 16 ГБ ОЗУ). При нехватке памяти загрузка оборвётся на этапе `initramfs`.

## Конструктор Ubuntu Autoinstall

На странице [Библиотека → Скрипты установки](/answers) нажмите «Добавить скрипт… → Ubuntu: Создать в редакторе». Встроенный конструктор формирует валидный NoCloud `user-data` (проверяется по JSON Schema) и `meta-data`, а пароли хешируются через `yescrypt`.

Конструктор разбит на **8 разделов**:

1. **Основные параметры:** язык, раскладка клавиатуры, часовой пояс, имя хоста.
2. **Учётная запись:** имя пользователя, пароль (хешируется в `yescrypt`), SSH-ключи и включение OpenSSH.
3. **Разметка диска (3 режима):**
   - ручная разметка в установщике;
   - автоматическая очистка выбранного диска;
   - автоматическая очистка строго по серийному номеру диска (защищает соседние диски от стирания).
4. **Сеть и зеркала пакетов:** локальное корпоративное зеркало `apt` или режим установки **без доступа к сети**.
5. **Пакеты и обновления:** список до 128 дополнительных пакетов.
6. **Наборы приложений и окружение.**
7. **Пользовательский скрипт после установки** (`/bin/sh -eu`, размер до 16 КиБ).
8. **Предпросмотр YAML** и скачивание готового `user-data` перед сохранением в библиотеку.

Готовый файл сохраняется в базе `omb_control` и выдаётся клиентам по HTTP через `/assets/ubuntu-autoinstall/...`. Как и для Windows, результаты ручных испытаний Ubuntu-сценариев можно фиксировать в колонке «Проверка» таблицы `/answers`.
