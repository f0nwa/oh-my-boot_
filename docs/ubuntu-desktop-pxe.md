# Первая загрузка Ubuntu Desktop по PXE

Подготовлен профиль для `ubuntu-26.04.1-desktop-amd64.iso` из подключённой SMB-папки. Boot отдаёт только этот ISO по `/images/ubuntu-desktop.iso`, а извлечённые из него `casper/vmlinuz` и `casper/initrd` — по `/assets/ubuntu/`. В меню Control пункт Ubuntu включается отдельным флажком; публикация сохраняет предыдущую версию для отката. Остальные ISO из SMB-папки по HTTP не выдаются.

После запуска ядра `casper` получает адрес по DHCP, скачивает ISO по HTTP и монтирует его. Это подтверждено разбором `scripts/casper` в initrd данного образа: параметры `iso-url=*.iso` и `url=*.iso` выбирают `NETBOOT=url`, затем `wget` загружает файл. Для ISO размером 6,5 ГБ тестовому клиенту выделено не менее 16 ГБ ОЗУ. Первая полноценная загрузка клиента ещё требует проверки; успешная выдача HTTP сама по себе не подтверждает запуск Live-системы или работу Secure Boot с этим ядром.

## Настройка

На сервере Boot должен иметь доступ на чтение к выбранному ISO: добавить `pxe-images` в `SupplementaryGroups` юнита `pxe-boot.service`. В `/etc/pxe-platform/boot.env` задать абсолютный путь к файлу:

```ini
PXE_BOOT_UBUNTU_ISO=/mnt/pxe-platform-smb/84e4b95528e2b8c5a405adb7061bc5bf/ubuntu-26.04.1-desktop-amd64.iso
```

В `/etc/pxe-platform/control.env` задать доступный клиентам адрес Boot:

```ini
PXE_CONTROL_BOOT_BASE_URL=http://10.30.0.10:8080
```

Ядро и initrd скопировать из того же ISO в `/srv/pxe/tftp/ubuntu/vmlinuz` и `/srv/pxe/tftp/ubuntu/initrd`; после копирования сравнить SHA-256 исходных файлов и копий. Затем обновить бинарные файлы Boot и Control, перечитать юниты и перезапустить обе службы. До публикации меню проверить `HEAD` для всех трёх URL и диапазонный `GET` ISO. Если SMB-подключение пропадёт, выдача ISO вернёт 404; диагностическое меню Boot продолжит работать.

## Проверка и откат

В HTTPS-админке открыть **Меню**, отметить **Ubuntu Desktop 26.04.1** и нажать **Опубликовать**. Затем запустить тестовую PXE-ВМ с 16 ГБ ОЗУ, выбрать Ubuntu и дождаться рабочего стола Live-системы. Проверить отдельно SeaBIOS, OVMF без Secure Boot и OVMF с Secure Boot. Сетевой доступ к меню до этой проверки уже работает, но совместимость загрузки ядра в трёх режимах пока не установлена.

При неудачной загрузке в админке **Меню → Версии** вернуть прежнюю диагностическую версию. На тестовом сервере прежние бинарные файлы, юнит и настройки сохранены в `/var/backups/pxe-platform-pre-ubuntu-20261016/`. Удаление пункта Ubuntu из меню не требует выключать PXE, DHCP или SMB-хранилище.
