# Windows 10: сетевая установка через WinPE в OMB

[English version](en/windows-winpe-pxe.md). Это руководство относится к текущим профилям ISO. Статические пункты и отдельные шары первых испытаний больше не используются; исходные отчёты доступны через [историю проекта](project-history.md).

## Подготовка

1. Подключите хранилище и найдите Windows 10 x64 ISO в библиотеке. Настройка Images и серверных компонентов описана в [руководстве хранилищ](images-installation.md).
2. Создайте профиль ISO и выполните «Подготовить». Дождитесь готовности. Исходный ISO должен оставаться доступным; одного `boot.wim` недостаточно для установки.
3. При необходимости загрузите Windows XML в «Библиотека → Файлы ответов», а INF с зависимостями — в «Библиотека → Драйверы».
4. Создайте установку Windows с этим профилем. Для ручного запуска оставьте файл ответов пустым; для автоматизации выберите проверенный XML. Укажите нужные INF и дождитесь подготовки WIM.
5. Добавьте установку в черновик меню и нажмите «Опубликовать». Публикация проверяет доступность зависимостей. Изменение черновика само по себе не меняет меню клиента.

Подробности выбора XML и драйверов — в [руководстве Control](control-installation.md#каталог-драйверов-winpe). В качестве примеров XML доступны [настройка языка](../examples/windows-answer-language-only.xml) и [ключ без выбора диска](../examples/windows-answer-key-no-disk.xml); соответствие конкретному ISO нужно проверить отдельно.

## Загрузка и диагностика

iPXE запускает WinPE через `wimboot`. Подготовленный `omb-setup.cmd` подключает установочный источник через шару `ombisos` от имени `omb-iso` и открывает Setup; выбранный XML передаётся установщику. Учётные данные NAS остаются на сервере. При недоступном источнике диагностируйте сеть WinPE, профиль ISO и SMB, а при невидимом диске — выбранный драйвер контроллера хранения.

Профиль Windows 10 ранее доходил до установщика и списка дисков в SeaBIOS. Для текущей сборки этот сценарий нужно повторить.

XML может выбирать и очищать диск. Для проверки только запуска используйте отдельную тестовую ВМ и XML без автоматической разметки. По сообщению пользователя от 01.11.2026 загрузка UEFI Secure Boot с XML и драйверами работает; завершение установки и весь набор сценариев этим не подтверждены.

## Возврат меню и повторная проверка

Вернуть опубликованную версию можно через «Меню → Версии», пока её зависимости доступны. Это не восстанавливает удалённые ISO и не отменяет изменения на клиентском диске. Восстановление серверного комплекта описано в [отдельном руководстве](recovery.md).

Полный прогон BIOS, UEFI с Secure Boot и без него, XML и драйверов отложен до завершения основной разработки. Текущее состояние — в [отчёте стенда](research/2026-10-31-omb-technical-migration.md).
